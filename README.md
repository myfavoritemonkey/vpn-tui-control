# vpn-tui-control

Интерактивный Rust-селектор подписки для sing-box. Он принимает HTTPS-ссылку, распознаёт обычный и Base64-список `vless://`/`ss://`, декодирует названия стран и регионов из URL, а затем создаёт TUN-конфигурацию sing-box.

## Сборка и запуск

```bash
cargo build --release
sudo ./target/release/vpn-tui-control
```

Установка команд для запуска из любой директории:

```bash
mkdir -p ~/.local/bin
install -m 755 target/release/vpn-tui-control ~/.local/bin/vpn-tui-control
ln -sf vpn-tui-control ~/.local/bin/vtc
```

После этого доступны команды `vpn-tui-control` и `vtc`.

Конфигурация по умолчанию сохраняется в `/etc/sing-box/config.json`, а ссылка — в `/etc/sing-box/subscription.url`. При следующем запуске достаточно нажать Enter на приглашении ссылки, чтобы использовать сохранённую подписку. Для теста без root можно указать другой путь:

```bash
./target/release/vpn-tui-control --output=/tmp/sing-box.json
```

После выбора интерфейс сам запускает и останавливает процесс sing-box. Управление в TUI:

- `↑` / `↓` — выбрать сервер;
- `Enter` — включить выбранный сервер или выключить активный;
- `R` — параллельно проверить TCP-доступность всех серверов;
- `T` — обновить список по сохранённой ссылке;
- `Z` — заменить ссылку подписки;
- `q` или `Esc` — выйти (VPN останавливается).

Проверка `p` измеряет доступность порта сервера, а не полноценный ICMP ping. Ошибки запуска sing-box записываются в `/tmp/vpn-selector-sing-box.log`.

При старте используется локальный кеш списка (`subscription.cache`), поэтому сеть для запуска интерфейса не нужна. Интерфейс использует панели с закруглёнными границами; активный сервер подсвечивается зелёным. Проверка выполняется в фоне: интерфейс остаётся отзывчивым, у каждого сервера отображается анимированный индикатор, а задержки появляются по мере завершения отдельных проверок.

Фоновое управление:

```bash
./target/release/vpn-tui-control start 11   # выбрать сервер №11 и запустить VPN
./target/release/vpn-tui-control start      # показать сервер, пинг и состояние
./target/release/vpn-tui-control status     # проверить состояние VPN
./target/release/vpn-tui-control on         # включить последний выбранный сервер
./target/release/vpn-tui-control off        # выключить VPN
```

Если запускать sing-box вручную, используется команда:

```bash
sudo sing-box run -c /etc/sing-box/config.json
```

Для TUN нужны права root, установленный `sing-box` и поддержка TUN. UUID и пароли не показываются в меню, но записываются в локальную конфигурацию, поскольку sing-box использует их для подключения.

Если `sing-box` ещё не установлен, программа всё равно сохранит конфигурацию и выведет предупреждение. Проверка конфигурации будет выполнена автоматически после установки sing-box при следующем запуске.
